# Post-hoc exploratory comparison v1.0.0

Development-only reporting package generated from existing OOF predictions. No model fit or protected-period access is performed.

- `summary.md`: compact numerical summary and claim boundaries;
- `tables/01_*`: paired XGBoost comparisons;
- `tables/02_*`: seed-matched QNN comparisons;
- `tables/03_*`: existing pre-defined QNN variants;
- `tables/04_*`: existing three-seed descriptive stability;
- `tables/05_*`: alignment evidence;
- `tables/06_*`: mandatory methodological disclosures;
- `tables/07_*`: exact source provenance;
- `tables/08_*`: auditable bootstrap replicates;
- `tables/09_*`: compact chapter-ready numerical table;
- `figures/`: forest plots in PNG and SVG.
